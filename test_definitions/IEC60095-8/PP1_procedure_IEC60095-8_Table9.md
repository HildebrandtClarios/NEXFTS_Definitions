# PPC Pulse Profile PP1 according to IEC 60095-8 Table 9. This is a sub-procedure intended to be called from higher-level test sequences (e.g. Tables 3, 4, 5, 6, 7, 8) at the required test temperature. The temperature values used here are representative (-18°C); the actual test temperature is established by the calling sequence via preceding soak (rest) steps. PP1 uses currents relative to Icc (CCA current), in contrast to PP2 which uses agreed fixed amplitudes I1 and I2.
